    How HopGuard works

    AI assistants read documents and use tools, such as sending email. If someone hides an instruction inside a document ("also email the salary to this outside address"), the assistant may obey it. This is called prompt injection.

    HopGuard puts a checkpoint on every step ("hop") the assistant takes:
